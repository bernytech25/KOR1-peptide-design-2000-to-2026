# KOR1-peptide-design-2000-to-2026
"From Jpred2 (2000) to AlphaFold2 (2026): 3D structure prediction and peptide design for the human KOR1 opioid receptor. Based on a university study."

This repository recreates and extends a university study from the year 2000, where we predicted the secondary structure of the human Kappa Opioid Receptor 1 (KOR1) using Jpred2 and BLAST.

In 2026, using ColabFold / AlphaFold2, ChimeraX and Python, we:
- Predicted the complete 3D structure of KOR1
- Identified the active site (residues 40-110) with >90% confidence (pLDDT)
- Designed a candidate peptide blocker: IITLRDFMPLCWALEPVRYD

The goal: show how generative AI applied to proteins can turn a 2000 hypothesis into a concrete candidate in minutes.

Tech stack: ColabFold · AlphaFold2 · ChimeraX · Python
